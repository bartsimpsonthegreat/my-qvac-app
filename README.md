# Local AI Generator (QVAC SDK)

An on-device local AI application built using Tether `@qvac/sdk`.

## QVAC Functions Called
- `loadModel`
- `completion`

## Dependencies
- `@qvac/sdk`: `^0.19.0`

## Run Instructions
1. Install: `npm install`
2. Run: `node index.js`
